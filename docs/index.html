Quick commands

Resolvé el Route desde el clúster al que estás logueado. Los FQDN OpenTLC rotan.

ROUTE=https://$(oc get route inference -n ocp-datalake -o jsonpath='{.spec.host}')
curl -sk -H 'Content-Type: application/json' \
  -d '{"tenure":12,"charges":70,"support_tickets":3}' \
  "$ROUTE/predict"

Hoy: conceptual alta, técnica baja. El flujo (registry → promoción → serving bajo política de clúster) está bien modelado. El contrato del artefacto no es MLflow: es un JSON de coeficientes, no un directorio MLmodel + model.pkl. No apuntes un registry de producción a este PoC.

EncajeQué entra
AltoLineal exportado a mano (coef_ / intercept_) → este JSON. Es churn-score v1, no “traer el modelo del registry”.
Mediosklearn / XGBoost / LightGBM: cambiar el ServingRuntime (MLServer + mlflow, o ONNX + OVMS/Triton). No parches server.py. Cuidado con pickle vs UBI 3.12.
BajoSpark ML, Feature Store / Unity Catalog en inferencia, rutas DBFS o volúmenes UC.

Falta el puente real: Unity Catalog (models:/catalog.schema.model/1), OAuth M2M (no un PAT en un Secret) y egress. Detalle en el README.
